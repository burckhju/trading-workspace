# ADR-S1-004 – Single-User und Single-Workspace

**Status:** Accepted
**Datum:** 2026-08-03

## Entscheidung

Version 1 besitzt einen Benutzer und einen technisch angelegten, in der UI unsichtbaren Workspace. Es gibt keine Benutzer-, Rollen-, Team- oder Workspace-Auswahl.

Workspacegebundene Fachobjekte erhalten eine konsistente Workspace-Zuordnung. Eine teilweise Einführung ist unzulässig.
