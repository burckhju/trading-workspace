# ADR-S1-005 – Deaktivierung und Löschung

**Status:** Accepted
**Datum:** 2026-08-03

## Entscheidung

Ein unbenutztes Underlying darf endgültig gelöscht werden. Sobald eine fachliche Referenz besteht, ist nur Deaktivierung zulässig. Deaktivierte Underlyings bleiben historisch sichtbar, sind standardmäßig aus neuen Auswahllisten ausgeschlossen und können reaktiviert werden.
