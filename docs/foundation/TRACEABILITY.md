# Zweck

Dieses Dokument definiert die projektweite Rückverfolgbarkeit zwischen Anforderungen, Entscheidungen, Implementierung, Tests, Releases, Datenquellen und Modellversionen.

# Verbindliche Kette

```text
Anforderung → Entscheidung → Implementierung → Test → Abnahme → Release → Beobachtung
```

Für fachliche Berechnungen zusätzlich:

```text
Datenquelle → Datenstand → Modellversion → Eingaben → Ergebnis → verwendender Trade
```
