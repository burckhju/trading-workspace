# Zweck

Zentrale Referenz für die versionierte REST-API des Trading Workspace. Konkrete Endpunkte werden ergänzt, sobald die jeweiligen Features spezifiziert werden.

# Verbindliche Regeln

- versionierte Pfade unter `/api/v1/`
- typisierte Ein- und Ausgaben
- stabile maschinenlesbare Fehlercodes
- Authentifizierung und Autorisierung an der Backendgrenze
- keine Geschäftslogik in Controllern
- Breaking Changes benötigen eine Versions- oder Migrationsstrategie
