# v0.4.0-market-analysis-rc.1

## Status

Release Candidate – nicht final freigegeben.

## Inhalt

Dieser Release Candidate enthält Sprint 4 / FT-006 Marktanalyse einschließlich:

- providerunabhängiger Marktanalyse auf persistierten internen Marktdaten;
- versioniertem Analysemodell und vollständig aufgelösten Parametern;
- unveränderlichen Marktdaten-Snapshots und SHA-256-Eingabe-Hash;
- Qualitätsstatus, Kriterien, Kennzahlen und Hinweisen;
- Analyse-Lifecycle mit append-only Events;
- Retry aus historischem Snapshot ohne erneuten Providerzugriff;
- Supersede-Historie ohne Mutation abgeschlossener Runs;
- technischer Reproduzierbarkeitsprüfung;
- REST API und React-Detail-/Übersichtsoberflächen;
- Pagination, Filter, CSV-Export und gespeicherten Ansichten;
- zentraler Request-Identity-Nahtstelle für den aktuellen Single-User-Betrieb.

## Verifikation

- Backend: 197 Tests bestanden.
- Backend Coverage: 87,20 %, Gate >= 85 % bestanden.
- Alembic: genau ein Head `20260806_0005`, lineare Revisionskette.
- Architecture Review: fachlich und architektonisch abnahmefähig.

## Blocker vor finalem Release

- Ruff/Black/mypy konnten wegen unvollständiger Python-Registry nicht frisch installiert werden.
- `npm ci` scheitert an fehlendem `yocto-queue@0.1.0` in der konfigurierten Registry.
- PostgreSQL/Docker sind in der Ausführungsumgebung nicht verfügbar.
- Dadurch bleiben Frontend-Quality-Gates, echter PostgreSQL-Migrationslauf und Playwright-E2E offen.

## Finalisierung
