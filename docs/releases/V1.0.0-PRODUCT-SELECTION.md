# v1.0.0 – Product Selection

## Feature

FT-008 Product Selection / Produktauswahl

## Summary

Trading Workspace now supports a transparent Product Selection workflow after an approved TradePlanVersion.

The system evaluates and compares products but does not make the final trading decision for the user.

## Included

- ProductSelectionRun
- reproducible ProductEvaluation
- explicit ProductSelection
- approved TradePlanVersion handoff
- historical Warrant / TermsVersion / Listing references
- Product Universe and Eligibility
- missing-data and exclusion reasons
- provider/data-quality provenance
- explicit ELIGIBLE-only V1 selection
- Product Selection REST API
- Product Selection frontend workflow
- PostgreSQL persistence
- WarrantListing provider mapping boundary
- browser-level E2E coverage

## Safety and decision boundary

Trading Workspace does not:

- automatically choose a warrant;
- generate an order;
- determine order quantity;
- determine position size;
- automatically trade.

The final ProductSelection remains an explicit user decision.

## Provider limitation

Live WarrantListing Bid/Ask remains fail-closed unless provider capability is explicitly verified for the actual FT-004 warrant universe.
