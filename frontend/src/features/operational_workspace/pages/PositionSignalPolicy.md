# Deutsche UI-Texte für Positionssignale

Die REST-API behält stabile technische Enum-Werte. Im Operativen Arbeitsbereich werden diese ausschließlich nutzerverständlich auf Deutsch dargestellt:

- `CRITICAL` → `Positionssignal: dynamischer Stop erreicht`
- `ATTENTION` → `Positionssignal: Gewinnschutz aktiv`
- `NORMAL` → `Positionssignal: keine besondere Aufmerksamkeit nötig`
- `STALE` → `Positionssignal: Daten veraltet`
- `MISSING` → `Positionssignal: Daten fehlen`
- `INSUFFICIENT` → `Positionssignal: noch nicht ausreichend Daten`
- sonstiger Fehler → `Positionssignal: Prüfung erforderlich`

Die Texte sind Hinweise, keine Verkaufs- oder Ausführungsempfehlung.
